# Overworld

Eight animated pixel biomes behind your Claude Code chat, each with a full colour palette for the app, switched with `/overworld`. Plus the Party: a pane where every subagent Claude sends out spawns in as a mob, with its live tool, exact tokens, an XP bar and a timer.

```
/plugin install overworld --marketplace abdullahafaq/claude-overworld
/overworld sakura
```

Biomes: `sakura`, `meadow` (light), `desert`, `aurora`, `ocean`, `end`, `nether`, `deep`. `/overworld` lists them, `/overworld still` stops the motion, `/overworld party off` closes the Party, `/overworld off` goes back to normal.

Needs the Claude Code desktop app (Code tab) for the backdrops; the Party also works in the terminal as text. It has no network, file or process access and saves three settings: your biome, the motion setting, and whether you closed the Party.

Everything else (screenshots, how to make your own biome, accessibility and privacy details) is in the [main README](https://github.com/abdullahafaq/claude-overworld#readme).
