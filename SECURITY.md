# Security policy

## What Overworld can reach

Very little on purpose. It changes the app's colours and backdrop, and shows your own agents in the Party pane. No network, filesystem, process or model access, no dependencies. It stores three settings locally. Agent text is trimmed and secret-looking strings are masked before they're kept, and only for the session.

## Found something?

Please don't file a public issue. Use [private vulnerability reporting](https://github.com/abdullahafaq/claude-overworld/security/advisories/new) with what you found, how to reproduce it, and your plugin version. I'll reply as soon as I can, and credit you in the fix if you'd like.

## Versions

Fixes go into the latest release only.
